# TalentPulse AI - Workforce Attrition Analytics

TalentPulse AI is an interactive web application that evaluates employee attrition risk based on key workplace and compensation metrics. 

## Tech Stack
* **Frontend:** HTML5, Tailwind CSS, JavaScript (Fetch API)
* **Backend:** Python, FastAPI, Pydantic
* **Deployment:** Vercel (Serverless Functions)

## Key Features
* Real-time risk probability calculation.
* Categorized risk tiering (Stable, Warning, Critical).
* Identification of key retention risk drivers based on logical thresholds.
